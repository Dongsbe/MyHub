# 내 하루 허브 (MyHub)

웹사이트와 자주 쓰는 PC 프로그램, 일정 등을 한 화면에서 관리하려는 개인용 WPF 데스크톱 앱입니다. 사용자가 코드를 직접 작성하며 WPF를 익히는 학습 프로젝트입니다.

## 현재 범위

지금은 홈 화면의 바로가기 영역과 바로가기 추가 창을 만드는 단계입니다. 로그인, 데이터 저장, 일정 연동, 아이콘 파일 선택과 실제 바로가기 생성은 아직 구현되지 않았습니다. 최신 상태는 [TODO.md](TODO.md)와 [작업 기록](docs/작업기록.md)을 확인하세요.

## 개발 환경과 실행

- C# / WPF
- 대상 프레임워크: `.NET 10` Windows (`net10.0-windows`)
- IDE: Visual Studio에서 `MyHub.slnx` 열기
- 실행: Visual Studio 상단의 시작(▶) 버튼으로 `MyHub` 프로젝트 실행

.NET 10 SDK와 Windows 데스크톱 개발 워크로드가 필요합니다. 프로젝트를 열 때 복원할 항목이 나타나면 복원을 완료한 뒤 실행합니다.

## 저장소 구성

```text
MyHub/
├─ AGENT.md                 # 사람과 AI가 함께 따를 학습·작업 지침
├─ AGENTS.md                # Codex가 읽는 지침 진입점
├─ TODO.md                  # 완료·진행 중·예정 작업
├─ docs/
│  ├─ 화면_디자인명세.md     # 화면 크기·배치·색·글자 명세
│  ├─ 버튼_기능명세.md       # 버튼별 동작과 미완료 동작
│  └─ 작업기록.md           # 단계별 작업 이력
├─ view/
│  ├─ HomeView.xaml         # 홈 화면 모양
│  ├─ HomeView.xaml.cs      # 홈 화면 버튼 동작
│  ├─ AddLinkWindow.xaml    # 바로가기 추가 창 모양
│  └─ AddLinkWindow.xaml.cs # 바로가기 추가 창 동작
├─ icon/                    # 화면에서 사용하는 PNG 아이콘
├─ MainWindow.xaml          # 앱 기본 창과 왼쪽 메뉴
└─ MyHub.csproj             # WPF 프로젝트와 이미지 리소스 설정
```

## 데이터와 계정

앱은 PC 한 대에서 혼자 사용하는 로컬 앱을 목표로 합니다. 서버·클라우드·계정 연동과 은행 자동 연동은 사용하지 않는 방향입니다. 로그인은 뒤 단계로 미뤄 두었습니다. 로컬 데이터 저장 방식은 기능을 붙이기 전에 SQLite 등 초보자가 관리하기 쉬운 선택지를 비교해 결정합니다.
