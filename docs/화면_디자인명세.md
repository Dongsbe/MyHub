## 6. 확인할 화면 조건

- [ ] 창 시작 크기 1280 × 800에서 전체 요소가 잘리지 않는다.
- [ ] 최소 크기 1050 × 680에서도 제목과 주요 카드가 겹치지 않는다.
- [ ] 최대화와 임의 크기 조절을 지원하도록 창 설정을 바꾼 뒤, 고정 메뉴와 본문이 의도한 비율로 보인다.
- [ ] 바로가기 1개, 여러 개, 행이 바뀌는 경우 타일 간격이 일정하다.
- [ ] 입력 창이 부모 앱 창의 중앙에 열린다.
- [ ] 모든 버튼의 기본·마우스 올림·누름·사용 불가 상태의 색을 정한다.
- [ ] 카드 외곽선이 필요한 영역은 선 색과 두께를 별도로 적는다.
